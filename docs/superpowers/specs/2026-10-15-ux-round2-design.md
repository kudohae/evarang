# 사용 경험 2차 (2026-10-15)

사용자 요청 다섯 가지와, 그에 따라 구현자가 정한 것. 사용자는 확인 사항을 모두 구현자에게 맡겼다.

## 1. 내 API 키가 막히면 알림 창

- 사다리가 `own:` 모델을 "오늘 끝"(키 거부, 하루 한도)으로 건너뛰는 순간 알림 창을 띄운다. 한 페이지에서 한 번만 띄운다.
  - 문구: "내 API 키를 지금 쓸 수 없습니다", 서버가 준 이유(거부 / 한도 소진), "이어서 사이트의 무료 AI로 평가합니다. 이때는 하루 한도가 적용됩니다."
  - 단추: "확인", "내 정보에서 키 확인".
- 페이지를 열 때 회원에게 키가 있는데 쓸 수 있는 `own:` 모델이 하나도 없어도 같은 창을 띄운다. 탭(세션)마다 한 번이다.
- 구현:
  - `lib/feedback/ladder.ts`는 `onOwnKeyOut(message)` 알림을 낸다(작은 이벤트 버스 `lib/client/notices.ts`).
  - `components/KeyOutDialog.tsx`가 그 알림을 듣고 창을 띄운다. 이 창은 `AccessGate` 안에 붙는다.

## 2. 마이크 연결 유지

- `MicrophoneProvider`를 루트 레이아웃에 둔다. 스트림을 페이지 이동, 연습 바꾸기, 단계 바꾸기와 상관없이 한 번 연결해 두고 계속 쓴다.
- 브라우저가 이미 허락한 사이트면(`permissions.query`가 `granted`) 페이지를 새로 열어도 단추 없이 바로 연결한다.
- 장치가 빠지거나 트랙이 끝나면 연결을 해제하고, 다시 연결 단추를 보여준다.
- `useMicrophone()`은 이 공유 상태를 읽는다. 모의고사도 같은 스트림을 쓴다.

## 3. 첨삭노트를 핵심 기능으로

- **위쪽 거르개**
  - 오답 유형(이름표 묶음 → 이름표) 칩: 장수와 오늘 복습할 수가 함께 보인다.
  - 상태 칩: 오늘 복습 · 전체 · 익힘 · 숨김.
  - 출처 칩: 모의고사 · 연습.
  - 고른 거르개가 목록과 "복습 시작"에 똑같이 적용된다("이 유형 n장 복습").
- **요약**: 전체 카드, 오늘 복습, 익힌 카드(상자 4 이상)를 숫자와 진행 막대로 보여준다.
- **카드 목록**
  - 한 줄: "내가 한 말"을 지우고 "고친 말"을 보여준다. 이유는 접혀 있다.
  - 펼치면 원래 질문, 출처(날짜·문항), 상자 단계를 보여준다.
  - 바로 쓰는 단추: 들어보기 · 이 카드만 연습 · 숨기기.
- **복습 화면**
  - 큰 카드 한 장과 진행 막대.
  - 순서: 말하기 → 결과에서 빠진 단어를 강조. 맞으면 바로 다음 카드로 넘어가고, 틀리면 정답을 들려준다.
  - 자동 판정이 틀렸을 때 "맞게 말했어요"로 바로잡을 수 있다.
  - 키보드: Space 정답 보기, 1 맞음, 2 틀림, Enter 다음.
- **카드 id 안정화**: 카드 id를 내용 기반(`${attemptId}:c:${hash(before|after)}`)으로 바꾼다. 다시 평가해도 같은 표현이면 같은 카드다. 예전 번호 id 상태는 처음 열 때 옮긴다.

## 4. 문장 구조화 연습 다시 만들기

- **흐름**
  1. 문제 유형과 주제를 고른다. 주제는 "아무 주제"도 된다.
  2. 질문이 나온다. 글자로 보이고, 들을 수 있다.
  3. 아래에 프레임 네 칸이 있다: 두괄식(바로 답하기) · 이유 · 예시 · 감정·생각.
     - 칸마다 따로 녹음한다. 같은 칸을 여러 번 녹음할 수 있다.
     - 녹음마다 바로 받아쓰고, 길이(초·단어 수)와 받아쓴 글을 보여준다.
     - 칸마다 "쓸 녹음"을 하나 고른다. 기본은 마지막 녹음이다.
  4. 네 칸이 모두 차면 "평가"를 누른다.
- **평가**: `POST /api/feedback/structure`가 한 번 호출로 칸별 판정을 낸다.
  - 칸별: 좋음 / 보통 / 부족, 길이 평, 내용 평, 더 나은 문장.
  - 종합: 흐름(칸 사이 연결), 총평, 네 칸을 이은 모범 답안.
  - 사다리 위에서 돌고, 사용량은 `feedback.answer`(단위 1, 참조는 연습 id)로 센다.
- **저장**: 연습을 `session` 문서(`kind: "structure"`, `settings: { type, topicId }`, `structure: { parts, feedback }`)로 저장한다. 녹음 키는 `${sessionId}:${part}-${n}`이다.
  - 계정 동기화는 지금처럼 따라간다. 화면에는 "지난 기록 · 준비 중"을 비활성으로 보여준다.
- 예전의 단계별 구조화 연습 화면과 단계 통과 표시는 없앤다. 렌즈 `structure.*`는 남겨 둔다.

## 5. 버튼과 전반의 손맛

- **돌아가기**: 모든 "돌아가기·고르기" 텍스트 링크를 `BackButton`으로 바꾼다. 아이콘과 테두리가 있는 작은 버튼이고, 누를 때 줄어들고 키보드 포커스 고리가 있다.
- **반응**
  - 저장·삭제·복습 결과에 작은 토스트를 띄운다(`Toast`, 2.4초, 화면 아래).
  - 칩은 눌린 상태(`aria-pressed`)가 색과 테두리로 바로 바뀐다.
  - 목록 카드는 마우스를 올리면 테두리가 진해지고, 누르면 살짝 눌린다.
  - 진행 막대는 부드럽게 늘어난다.
  - 처리 중인 단추는 같은 자리에서 스피너로 바뀐다(모양이 튀지 않게).
- **움직임**: 기존 `rise`와 같은 짧은 등장. `prefers-reduced-motion`이면 끈다.

## 6. 시험

- 단위 테스트:
  - 사다리 알림
  - 카드 id(내용 기반)와 예전 id 옮기기
  - 거르개 계산
  - 빠진 단어
  - 구조화 응답 스키마
  - 구조화 세션 녹음 키
- e2e:
  - 첨삭노트 거르개와 복습(자기 채점 / 말하기)
  - 구조화 연습 네 칸 녹음 → 평가
  - 마이크가 연습을 바꿔도 다시 묻지 않음
  - 키 막힘 알림(가짜 응답)
